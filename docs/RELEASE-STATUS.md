# Native server release status

Updated: 7 October 2026.

Acore LSP 0.1.0 and 0.1.1 downloads have been withdrawn while the maintainers prepare a corrected release. Do not install or redistribute these versions or use them as rollback candidates. Existing downloaded copies cannot be recalled.

A verified replacement version and installation instructions will be published here when available. Automatic native downloads remain disabled. The Apache-2.0 adapter and grammar source remain available; the native compiler has separate distribution and licensing.

This withdrawal does not indicate a confirmed production credential compromise or malicious server behavior.
