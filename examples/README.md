# Small offline authoring examples

Open this directory as a Zed worktree. Each child is a separate project owner.
Configure the compatible server through [settings](../docs/SETTINGS.md).
The original four examples need no remote packages, runtime, database connection
or CLI. The thirteen [expanded starters](authoring/README.md) include a separate
full application companion whose local backend artifact and UI lock must first
be prepared by explicit CLI commands.
For CLI checks use the child directory as `--root`, not this outer directory.
These are newly authored public examples, not copies of internal evidence.
